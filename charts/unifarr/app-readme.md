# Unifarr

Unified media management for movies and TV shows.

## Features

- 🎬 **Movie Management** - Organize and track your movie collection
- 📺 **TV Show Monitoring** - Automatically download new episodes
- 🔍 **Smart Search** - Multi-source torrent search (1337x, YTS, Webshare)
- 🎯 **Auto Matching** - Diacritics-aware file matching to TMDB
- 📝 **Custom Templates** - Per-show search templates for better results
- 🔄 **Auto Organization** - Automatic file organization and renaming
- 🌐 **Modern UI** - Beautiful, responsive web interface

## What It Does

Unifarr monitors your media folders, matches files to TMDB metadata, tracks TV show episodes, and automatically downloads new content when available. Perfect companion for Plex, Jellyfin, or Emby.

## Configuration

After installation:
1. Access web UI at `http://[truenas-ip]:3000`
2. Login with `admin` / `admin123` (change immediately!)
3. Go to Settings → Libraries to verify paths
4. Add shows to monitor in Library → TV Shows
5. Configure search providers in Settings → Search Templates
